# Codext — SaaS Landing Page

A responsive SaaS landing page built with HTML and Tailwind CSS, based on a design from Figma Community.

## About the Project

Codext is a modern landing page designed to present software services with a clean layout, attractive visuals, and a user-friendly experience.

This project is part of my personal web development learning journey, where I practice building responsive websites from Figma designs.

## Built With

- HTML5
- Tailwind CSS

## Features

- Responsive design
- Modern and clean user interface
- Navigation menu
- Hero section
- Services and pricing sections
- Testimonials and blog sections
- Footer with social media links

## Getting Started

1. Clone the repository:

   ```bash
   git clone git@github.com:wahid-codes/Codext.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Codext
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the Tailwind CSS development process:

   ```bash
   npm run watch
   ```

5. Open `index.html` in your browser.
